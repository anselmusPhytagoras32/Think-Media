# Workspace assistance

Operate mode. Students find learning and opportunities, preserve useful
resources and maintain their own profiles. Instructors prepare editable drafts;
companies prepare their own listing drafts. Administrators reach existing
review screens. Hiring decisions and privileged approvals stay on those screens.

The guidance conversation retains the existing typography, purple actions,
fixed composer, mobile sheet, sources and recovery controls. A tool response
shows actual result links or a readable proposed change. Confirm and Cancel are
separate explicit actions. Long proposed text expands in place before approval;
it is never silently truncated from the submitted change. Saving refreshes
affected data across the workspace. External links and arbitrary code are not
assistant actions.

Lesson detail provides Explore OJT opportunities and Update my profile links.
A quiz score does not automatically add skills or claim mastery. The selected
published lesson can supply public context to guidance; private application and
profile objects cannot. Real-user usability and research effectiveness remain
unmeasured.
