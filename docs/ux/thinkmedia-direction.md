# ThinkMedia workspace refinement

Mode: Operate. Preserve the established green navigation, local fonts and semantic colors. Refine the task model and hierarchy across the existing screens; no replacement brand or marketing surface.

First viewport: the signed-in role's current work and next useful action. Students see applications and learning/opportunity entry points; companies see listing/applicant activity and verification; administrators see pending review queues. Empty queues explain how work arrives. No fabricated activity or decorative achievement metrics.

Navigation: conventional links with stable URLs, browser Back/reload, compact mobile task navigation and accessible overflow drawer. Profile is account maintenance rather than the main product experience.

Copy: plain English centered on OJT, learning, applications and review. Remove promotional slogans. Keep suggestions distinct from decisions and resource lookup distinct from external AI.
